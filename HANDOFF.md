## Guide #43 lessons and other recent QA fixes

- Reimbursement must not exceed initial expenses, but the input should allow free typing and clamp **on blur**. Use a safe capped effective reimbursement in calculations while editing.
- A conditional payback assumes a raise occurs even when probability is zero; label it as conditional. Separate optional time valuation from cash expenses, and scenario-weighted estimates from forecasts.
- React `react-hooks/refs` errors occurred when ref-reading analytics handlers were captured by field-descriptor arrays rendered with `.map`. The certification calculator used `useState` for its started flag. Do not disable lint to bypass this.
- Top-align inputs and notes in grids; verify wrapped labels, cards, and PDF/rendered layout. JSX closing tags and apostrophe escaping have previously caused lint/build failures.
- `scripts/check-source-links.mjs` was introduced in the Guide #43 package; verify it exists in the current checkout. A 403 or timeout requires manual review, not automatic link rejection. External source URLs have broken before; check them before shipping.

## Publishing workflow

1. Inspect current repository and confirm registry count and cluster IDs.
2. Research SERP, evidence, decision variables, and differentiation before coding.
3. Create guide-specific page/tool and registry entry; preserve language-aware routing and meaningful clusters.
4. Independently calculate default and boundary-case outputs; test negative/no-payback, dependent inputs, text labels, and visual alignment.
5. Run `npm run validate-guides`, `npm run lint`, `npm run build`; run source-link checker if present and manually verify important links.
6. Review rendered guide, commit/push, confirm production page and sitemap.
7. Notify IndexNow **after** deployment, then monitor search performance without overreacting to small samples.

**Working preference:** ship useful, well-tested guides with minimal unnecessary refactoring. Preserve existing project conventions and avoid repeated low-value QC loops.
